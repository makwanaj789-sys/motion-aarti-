# GPT Astra 6 v3: Alight Motion project (XML)

`GPT_Astra_6_v3.xml` is an Alight Motion project (1920×1080, 60 fps, 14.6 s). It is generated by `build_alight_xml.py` from the same measured timing map as the Remotion video (`src/AstraV3.tsx`).

Every animated value was sampled at 60 fps and stored as keyframes. Keys that a straight line already reproduces were removed.

## What is inside

| Kind | Content |
|---|---|
| Layers | 275 layers, ~7,450 keyframes |
| Camera shots | The chat UI and the code are nested scenes ("Chat UI (camera)", "Code (camera)"). Their location and scale keyframes are the camera path measured from the reference |
| Text | Every letter of ChatGPT / Writing / Coding / Research is its own text layer. Fonts: Inter and Fraunces, from Alight Motion's Google Fonts |
| Logo | `chatgpt_logo_white.png`, also saved as `AF8B34922D2788986F96F693A55C786BB9F96071.png` |
| Audio | `reference_audio.wav`, the reference video's original song. It is only in the zip, not in git |

## Import

1. Unzip the package on your phone.
2. In Alight Motion, import the `.xml` file. Depending on your version, this is Projects → `+` / Import, or opening the file with Alight Motion.
3. If a layer shows **missing media**, tap it, choose replace, and pick the file:
   - logo layers → `chatgpt_logo_white.png` (5 layers: lockup, greeting, reply, end logo, outro)
   - "Reference audio" → `reference_audio.wav`
4. Let Alight Motion download the fonts if it asks (Inter, Fraunces).

## How it was checked

- **Format.** The XML follows Alight Motion's own exported presets inside the APK, plus the community format docs. Keyframe `t` is a 0–1 fraction of the layer's duration, location is in canvas pixels, and edge decorations go before shape properties. It passes that project's scene validator with 0 errors. The 5 warnings are the custom path shapes (pointer, chevrons, ticks), which is expected for imported shapes.
- **Layout and timing.** `preview_xml.py` draws the XML the way the generator assumes the app reads it, and the result matches the v3 render frame for frame at the tested timestamps.
- **Not opened in the app.** The XML has not been opened in Alight Motion itself; no Alight Motion install was available. Small differences are possible, especially in:
  - **text vertical position:** the font line-box metrics may differ by a few px;
  - **Gaussian blur strength:** Alight Motion's strength is not in pixels; ~px/40 is used;
  - **glow look:** the app's Glow effect is used, not the browser's;
  - **light falloff:** a linear radial gradient stands in for the soft gaussian falloff;
  - **motion blur:** the app's own Motion Blur is on the two camera scenes (tune 0.6). Turn it off if you want it crisper, like the reference.

## Regenerate

```bash
pip install fonttools brotli resvg-py
python3 alight/build_alight_xml.py <out_dir>                       # XML + logo PNG (+ audio if public/audio/reference.wav exists)
python3 alight/preview_xml.py <out_dir>/GPT_Astra_6_v3.xml <out_dir> <preview_dir> 2.9 5.6 9.6   # layout preview
```
